# 🚀 PG Node SSH Tunnel Manager (`v6.5`)

ابزار خط فرمان و خودکار برای راه‌اندازی و مدیریت **تانل معکوس SSH در بستر `TLS 1.3` به سبک `Trojan` همراه با استتار واقعی وب (`Active-Prober Proof`)، تشخیص خودکار گواهی معتبر `Let's Encrypt` سرور ایران و سوییچ خودکار چند-آی‌پی (`Sticky Multi-IP Failover`)** میان **پنل PasarGuard (سرور ایران)** و **نود خارج**.

در نسخه‌ی **`v6.5`**، حتی ربات‌های **Active Prober** زیرساخت هم قادر به تشخیص تانل نیستند؛ زیرا سرور ایران هرگز هدر `SSH-2.0` را اول ارسال نمی‌کند، گواهی واقعی `Let's Encrypt` دامنه‌ی خود سرور ایران (از والیوم `Caddy` یا `Certbot`) را ارائه می‌دهد، و در صورت مراجعه مرورگر یا اسکنر، وب‌سایت واقعی روی پورت `80` را نمایش می‌دهد.

---

## ✨ ویژگی‌ها و قابلیت‌های کلیدی (`v6.5`)

- **🛡️ ضد Active Prober به سبک `Trojan` + استتار وب واقعی (`Zero SSH Banner Leak`):**
  - سرور ایران (`pg-tls-server.service`) هیچ بایتی را پیش‌دستانه ارسال نمی‌کند و تنها در صورت دریافت کلید مخفی مشترک (`TLS_SECRET`) درون هدر HTTP با طول تصادفی (`Randomized Padding`) به `127.0.0.1:22` متصل می‌شود.
  - هر اسکنر، مرورگر یا Active Prober زیرساخت که به پورت تانل متصل شود، مستقیماً به وب‌سرور واقعی محلی (`127.0.0.1:80` مانند `Caddy`) هدایت شده و پاسخ واقعی HTTP دریافت می‌کند.
- **🔐 تشخیص و تمدید خودکار گواهی معتبر `Let's Encrypt / Caddy`:**
  - هنگام پیکربندی سرور ایران، به صورت خودکار والیوم‌های Docker (`Caddy`)، مسیرهای `Certbot` (`/etc/letsencrypt/live`) و `acme.sh` اسکن شده و دامنه‌ی واقعی و گواهی معتبر `ECDSA / RSA` استخراج و به صورت ساعتی همگام‌سازی می‌شود.
- **⚡ موتور غیرمسدودکننده‌ی تک‌رشته‌ای (`Single-Threaded Non-Blocking MemoryBIO`) + حذف آنی پورت‌های زامبی:**
  - انتقال فول‌دوپلکس `4+ Gbps` بدون کوچک‌ترین قفل‌شدگی (`SSL_read`/`SSL_write` بدون تداخل رشته‌ای).
  - آزادسازی آنی (`<50ms`) پورت‌های `NODE_PORT` و `DATA_PORTS` پیش از اتصال مجدد `sshd` (صفر شدن کامل خطای `Address already in use` روی پورت `62075`).
  - مقاوم‌سازی خودکار `sshd` در برابر حملات Brute-Force ربات‌ها روی پورت ۲۲ (`MaxStartups 150:30:300` و `LoginGraceTime 20` در ابتدای فایل کانفیگ).
- **🌐 سوییچ خودکار و هوشمند چند-آی‌پی (`Sticky + Round-Robin Multi-IP Failover`):**
  - بررسی کامل سلامت تا دریافت واقعی بنر `SSH-` روی هر آی‌پی مبدا (`BIND_IPS`) و ذخیره‌ی آی‌پی سالم در `/etc/pg-tunnel/last_good_ip`.
- **📊 مانیتور زنده تک‌صفحه‌ای (`Option 2`) + کرون‌جاب هوشمند بدون قطعی (`Option 8`) + آپدیتر مستقیم شاخه/کامیت (`Option 6`).**

## 🛠️ نصب و راه‌اندازی سریع

### پیش‌نیازها
- سیستم‌عامل **Ubuntu 20.04 / 22.04 / 24.04** یا **Debian 11 / 12** با دسترسی `root`
- تنظیم آدرس نود خارج در پنل PasarGuard روی `127.0.0.1` و پورت مدیریت نود (مثلاً `62075`)

### دستور نصب اولیه روی هر دو سرور (ایران و خارج)

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/XiliService/pg-node-ssh-tunnel/main/script.sh)
```

پس از اولین اجرا، ابزار به صورت سراسری نصب شده و از هر مسیر با دستور زیر قابل اجراست:

```bash
pg-tunnel
```

## 📖 مراحل راه‌اندازی گام‌به‌گام

### گام ۱: پیکربندی سرور ایران (`Main / Panel Server`)
1. دستور `pg-tunnel` را اجرا کرده، گزینه‌ی **`1`** و سپس **`1) Iran Server`** را انتخاب کنید.
2. مقادیر زیر را وارد نمایید (در صورت وجود تنظیمات قبلی، مقادیر فعلی به عنوان پیش‌فرض نمایش داده می‌شوند):
   - **`Foreign Server IP`:** آی‌پی سرور خارج که در Outboundهای PasarGuard تعریف شده است.
   - **`Node management port`:** پورت مدیریت نود خارج (پیش‌فرض: `62075`).
   - **`Outbound data ports`:** پورت‌های دیتای تانل جداشده با کاما (مثلاً `64483,26132,22971`).
   - **`Anti-DPI HTTPS Port`:** پورت آزاد پیشنهادی استاندارد HTTPS (پیش‌فرض: `2087`).
   - **`TLS Cover Domain (SNI)`:** دامنه‌ی واقعی سرور ایران که به طور خودکار از گواهی `Caddy / Let's Encrypt` شناسایی می‌شود (فقط `Enter` بزنید).
   - **`Anti-Prober Secret Key`:** کلید مخفی تولیدشده‌ی خودکار (فقط `Enter` بزنید).
3. در پایان، کادر خلاصه‌ی مشخصات (`Iran Server IP`, `TLS Port`, `TLS SNI Domain`, `TLS Secret Key`) نمایش داده می‌شود تا مستقیماً در سرور خارج وارد کنید.

### گام ۲: پیکربندی سرور خارج (`Foreign Node Server`)
1. روی سرور خارج دستور `pg-tunnel` را اجرا کرده، گزینه‌ی **`1`** و سپس **`2) Foreign Server`** را بزنید.
2. مشخصات نمایش‌داده‌شده در سرور ایران (`IP`، پورت `2087`، دامنه‌ی `SNI` و `TLS Secret Key`) به همراه پورت نود و پورت‌های دیتا را وارد کنید.
3. در بخش **`Source Bind IPs`** می‌توانید آی‌پی‌های تمیز کارت شبکه را با کاما وارد کنید یا برای حالت خودکار خالی بگذارید.
4. اگر کلید عمومی از قبل روی سرور ایران ثبت شده باشد، بدون نیاز به رمز عبور و در کمتر از ۲ ثانیه سرویس پایدار متصل می‌شود.

## 📋 راهنمای منوی مدیریت (`pg-tunnel`)

| گزینه | عنوان | عملکرد |
| :---: | :--- | :--- |
| **`1`** | **Install / Configure Tunnel** | نصب یا بازپیکربندی سریع سرور ایران / خارج با پیش‌فرض‌های هوشمند |
| **`2`** | **Check Status / Rules & Live Speed** | داشبورد زنده‌ی تک‌صفحه‌ای سرعت، مصرف کل، گواهی SSL و آی‌پی فعال |
| **`3`** | **Uninstall Safely** | حذف ایمن سرویس‌ها و قوانین اختصاصی پروژه بدون اختلال در Docker و SSH |
| **`4`** | **View Tunnel Logs** | نمایش زنده‌ی لاگ‌های سرویس تانل در هر دو سرور ایران و خارج |
| **`5`** | **Network Optimizer** | بهینه‌سازی کرنل لینوکس، فعال‌سازی `TCP BBR + fq` و افزایش بافرهای شبکه |
| **`6`** | **Update Script (from GitHub)** | بررسی نسخه‌ی `main` یا دریافت مستقیم آخرین کامیت از شاخه/SHA دلخواه بدون نیاز به PR/Merge |
| **`7`** | **Repair / Restart Tunnels** | بازسازی و ری‌استارت فوری سرویس‌ها از روی فایل تنظیمات ذخیره‌شده |
| **`8`** | **Setup Auto-Restart Cronjob** | بررسی دوره‌ای هوشمند سلامت سرویس بدون قطع کردن تانل‌های سالم |
| **`0`** | **Exit** | خروج از برنامه |

## 🤖 قوانین معماری و توسعه

1. تمامی متون، پیام‌ها و کامنت‌های داخل `script.sh` باید ۱۰۰٪ انگلیسی (ASCII خالص) باشند.
2. هرگز کل جدول NAT فلاش نشود و فقط قوانین هدفمند پروژه با `-C` / `-A` / `-D` مدیریت شوند.
3. هرگز پروسه‌ی اصلی SSH به صورت اجباری متوقف نشود؛ مدیریت فقط با `systemctl reload/restart ssh.service` انجام شده و `Port 22` حفظ گردد.
4. هیچ نام شاخه‌ی کاری یا هش کامیت به صورت ثابت در کد یا فایل وضعیت روی دیسک ذخیره نشود.
